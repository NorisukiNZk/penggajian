Buku Saku Simulasi Ujian Skripsi
Panduan Praktis Live Coding CRUD & Tambah Fitur (CodeIgniter 3)
Aplikasi Penggajian & Absensi Pegawai Berbasis Web
Tujuan Panduan: Menyiapkan mahasiswa agar siap, tenang, dan terstruktur saat dosen penguji meminta uji coba langsung (live coding) membuat fitur CRUD baru, menambah kolom/field baru, atau membuat cetak laporan baru pada sistem skripsi.

1. Mindset Utama & Strategi Ujian

  • Dosen bukan menguji hafalan sintaks dari nol, melainkan memastikan apakah mahasiswa benar-benar memahami arsitektur program dan alur data dari frontend ke database.
  • Gunakan Prinsip ATM (Amati, Tiru, Modifikasi): Selalu buka file yang sudah berjalan normal di project Anda (seperti Data_jabatan.php), lalu jadikan acuan.
  • Respon Awal yang Profesional: Jawab dengan sopan dan tenang: "Baik Pak/Bu, saya siapkan struktur tabelnya di database terlebih dahulu, lalu membuat Controller dan View-nya."

2. Rumus 4 Langkah Emas (Pola Alur CI3)

Setiap kali diminta membuat fitur CRUD baru, selalu ikuti 4 tahapan ini secara berurutan:

Langkah Lokasi File / Tool Fungsi Utama
1. Database phpMyAdmin (MySQL) Membuat tabel baru atau menambah kolom tabel.
2. Controller application/controllers/admin/ Mengatur logika (Read, Create, Update, Delete).
3. View application/views/admin/ Membuat tampilan form input, tabel data, & form edit.
4. Sidebar views/template_admin/sidebar.php Menambahkan link menu navigasi di sidebar dashboard.
CATATAN PENTING (Model CI3): Di project Anda, ModelPenggajian.php sudah memiliki fungsi universal: get_data($table), insert_data($data, $table), update_data($table, $data, $where), dan delete_data($where, $table). Anda tidak perlu membuat query manual di Model untuk tabel master baru!

3. SKENARIO 1: Membuat CRUD Entitas Baru dari Nol

Contoh Permintaan Penguji: "Coba buatkan modul CRUD baru untuk Data Departemen / Divisi!"

Langkah 1 Buat Tabel di phpMyAdmin

Buka http://localhost/phpmyadmin > pilih database penggajian Anda > jalankan query SQL berikut:

CREATE TABLE data_departemen (
    id_departemen INT(11) AUTO_INCREMENT PRIMARY KEY,
    kode_departemen VARCHAR(20) NOT NULL,
    nama_departemen VARCHAR(100) NOT NULL
);

Langkah 2 Buat Controller Baru

Buat file baru di: application/controllers/admin/Data_departemen.php

<?php
class Data_departemen extends CI_Controller {

    public function __construct(){
        parent::__construct();
        if($this->session->userdata('hak_akses') != '1'){
            redirect('login');
        }
    }

    // 1. TAMPIL DATA (READ)
    public function index() {
        $data['title'] = "Data Departemen";
        $data['departemen'] = $this->ModelPenggajian->get_data('data_departemen')->result();

        $this->load->view('template_admin/header', $data);
        $this->load->view('template_admin/sidebar');
        $this->load->view('admin/departemen/data_departemen', $data);
        $this->load->view('template_admin/footer');
    }

    // 2. FORM TAMBAH (CREATE)
    public function tambah_data() {
        $data['title'] = "Tambah Data Departemen";
        $this->load->view('template_admin/header', $data);
        $this->load->view('template_admin/sidebar');
        $this->load->view('admin/departemen/tambah_data_departemen', $data);
        $this->load->view('template_admin/footer');
    }

    // PROSES SIMPAN DATA BARU
    public function tambah_data_aksi() {
        $this->form_validation->set_rules('kode_departemen', 'Kode Departemen', 'required');
        $this->form_validation->set_rules('nama_departemen', 'Nama Departemen', 'required');

        if($this->form_validation->run() == FALSE) {
            $this->tambah_data();
        } else {
            $data = array(
                'kode_departemen' => $this->input->post('kode_departemen'),
                'nama_departemen' => $this->input->post('nama_departemen'),
            );
            $this->ModelPenggajian->insert_data($data, 'data_departemen');
            $this->session->set_flashdata('pesan', '<div class="alert alert-success">Data berhasil ditambahkan!</div>');
            redirect('admin/data_departemen');
        }
    }

    // 3. FORM EDIT (UPDATE)
    public function update_data($id) {
        $where = array('id_departemen' => $id);
        $data['title'] = "Update Data Departemen";
        $data['departemen'] = $this->db->get_where('data_departemen', $where)->result();

        $this->load->view('template_admin/header', $data);
        $this->load->view('template_admin/sidebar');
        $this->load->view('admin/departemen/update_data_departemen', $data);
        $this->load->view('template_admin/footer');
    }

    // PROSES UPDATE PERUBAHAN
    public function update_data_aksi() {
        $id = $this->input->post('id_departemen');
        $data = array(
            'kode_departemen' => $this->input->post('kode_departemen'),
            'nama_departemen' => $this->input->post('nama_departemen'),
        );
        $where = array('id_departemen' => $id);
        $this->ModelPenggajian->update_data('data_departemen', $data, $where);
        $this->session->set_flashdata('pesan', '<div class="alert alert-success">Data berhasil diupdate!</div>');
        redirect('admin/data_departemen');
    }

    // 4. HAPUS DATA (DELETE)
    public function delete_data($id) {
        $where = array('id_departemen' => $id);
        $this->ModelPenggajian->delete_data($where, 'data_departemen');
        $this->session->set_flashdata('pesan', '<div class="alert alert-danger">Data berhasil dihapus!</div>');
        redirect('admin/data_departemen');
    }
}

6. Troubleshooting Cepat (Penanganan Error Live)

Jika saat demonstrasi muncul pesan error, jangan panik! Gunakan panduan diagnosa cepat ini:

Pesan Error Penyebab Utama Solusi Cepat
404 Page Not Found Nama file Controller salah atau huruf besar/kecil tidak sesuai. Pastikan nama class dan nama file Controller diawali huruf kapital (contoh: Data_departemen.php & class Data_departemen).
Unknown column 'xxx' in field list Nama kolom di array $data Controller tidak sama dengan kolom tabel di database. Buka phpMyAdmin, cek ejaan kolom di tabel. Samakan key array di Controller dengan nama kolom database.
Undefined variable: xxx Variabel yang dipanggil di View belum dikirim dari Controller. Cek Controller, pastikan ada $data['xxx'] = ... saat memanggil $this->load->view('...', $data);.
A PHP Error was encountered Objek kosong atau memanggil properti/kolom yang salah. Cek variabel loop di foreach view dan pastikan nama properti objek $d->nama_kolom sudah sesuai.
Tips Sikap Saat Terjadi Error Live:
Katakan dengan tenang: "Mohon maaf Pak/Bu, terdapat kesalahan penamaan kolom pada query controller, saya sesuaikan sekarang.". Dosen justru sangat mengapresiasi mahasiswa yang mampu membaca error log dan memperbaiki kodenya secara cepat dibanding yang panik.
