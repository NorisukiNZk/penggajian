Studi Kasus: Inventaris Buku & Peminjaman Buku (Framework CI3)
Panduan Lengkap Arsitektur MVC & Logika Transaksi / Relasi
Kabar Baik Menggunakan CI3 (Bukan Native PHP): Anda justru jauh lebih diuntungkan dibanding teman Anda yang memakai PHP Native! Di CI3, koneksi database sudah aktif, template SB Admin 2 sudah siap, styling Bootstrap otomatis rapi, dan fungsi CRUD di ModelPenggajian.php siap pakai. Anda bisa membuat fitur dalam waktu 5-8 menit saja tanpa mengetik kode koneksi manual yang panjang.

1. Arsitektur 2 Pola Fitur yang Biasa Diuji Dosen

Ketika dosen penguji melempar tema tertentu (misal: Perpustakaan, Gudang, Rental, dll.), ujian hanya terbagi menjadi 2 tipe:

Tipe Fitur Contoh Kasus Penguji Pola Logika di Framework CI3
Tipe 1: Master Data (Inventaris) Data Buku, Data Barang, Data Obat, Data Kamar. CRUD Murni: Form input → Simpan ke tabel inventaris_buku → Tampil di tabel → Edit → Hapus.
Tipe 2: Transaksi (Peminjaman) Peminjaman Buku, Peminjaman Alat, Penyewaan. Relasi & Update Stok: Dropdown pilihan buku dari database → Simpan peminjaman → Kurangi stok buku → Tombol kembalikan buku (+stok kembali).

2. STUDI KASUS A: INVENTARIS BUKU (MASTER DATA CRUD)

Dosen: "Coba buatkan sistem inventaris buku untuk mencatat judul, pengarang, dan stok buku!"

1. Database Buat Tabel di phpMyAdmin

CREATE TABLE inventaris_buku (
    id_buku INT(11) AUTO_INCREMENT PRIMARY KEY,
    kode_buku VARCHAR(20) NOT NULL,
    judul_buku VARCHAR(150) NOT NULL,
    pengarang VARCHAR(100) NOT NULL,
    kategori VARCHAR(50) NOT NULL,
    stok INT(11) NOT NULL DEFAULT 0
);

2. Controller application/controllers/admin/Inventaris_buku.php

<?php
class Inventaris_buku extends CI_Controller {

    public function __construct(){
        parent::__construct();
        if($this->session->userdata('hak_akses') != '1'){ redirect('login'); }
    }

    // 1. READ DATA BUKU
    public function index() {
        $data['title'] = "Data Inventaris Buku";
        $data['buku'] = $this->ModelPenggajian->get_data('inventaris_buku')->result();

        $this->load->view('template_admin/header', $data);
        $this->load->view('template_admin/sidebar');
        $this->load->view('admin/inventaris_buku/data_buku', $data);
        $this->load->view('template_admin/footer');
    }

    // 2. FORM TAMBAH
    public function tambah_buku() {
        $data['title'] = "Tambah Inventaris Buku";
        $this->load->view('template_admin/header', $data);
        $this->load->view('template_admin/sidebar');
        $this->load->view('admin/inventaris_buku/tambah_buku', $data);
        $this->load->view('template_admin/footer');
    }

    // SIMPAN BUKU BARU
    public function tambah_buku_aksi() {
        $data = array(
            'kode_buku'   => $this->input->post('kode_buku'),
            'judul_buku'  => $this->input->post('judul_buku'),
            'pengarang'   => $this->input->post('pengarang'),
            'kategori'    => $this->input->post('kategori'),
            'stok'        => $this->input->post('stok'),
        );
        $this->ModelPenggajian->insert_data($data, 'inventaris_buku');
        $this->session->set_flashdata('pesan', '<div class="alert alert-success">Buku berhasil ditambahkan!</div>');
        redirect('admin/inventaris_buku');
    }

    // 3. FORM EDIT
    public function update_buku($id) {
        $where = array('id_buku' => $id);
        $data['title'] = "Update Data Buku";
        $data['buku'] = $this->db->get_where('inventaris_buku', $where)->result();

        $this->load->view('template_admin/header', $data);
        $this->load->view('template_admin/sidebar');
        $this->load->view('admin/inventaris_buku/update_buku', $data);
        $this->load->view('template_admin/footer');
    }

    // SIMPAN UPDATE
    public function update_buku_aksi() {
        $id = $this->input->post('id_buku');
        $data = array(
            'kode_buku'   => $this->input->post('kode_buku'),
            'judul_buku'  => $this->input->post('judul_buku'),
            'pengarang'   => $this->input->post('pengarang'),
            'kategori'    => $this->input->post('kategori'),
            'stok'        => $this->input->post('stok'),
        );
        $where = array('id_buku' => $id);
        $this->ModelPenggajian->update_data('inventaris_buku', $data, $where);
        $this->session->set_flashdata('pesan', '<div class="alert alert-success">Data buku berhasil diupdate!</div>');
        redirect('admin/inventaris_buku');
    }

    // 4. HAPUS BUKU
    public function delete_buku($id) {
        $where = array('id_buku' => $id);
        $this->ModelPenggajian->delete_data($where, 'inventaris_buku');
        $this->session->set_flashdata('pesan', '<div class="alert alert-danger">Buku berhasil dihapus!</div>');
        redirect('admin/inventaris_buku');
    }
}

3. STUDI KASUS B: PEMINJAMAN BUKU (TRANSAKSI & RELASI)

Dosen: "Coba buatkan fitur peminjaman buku. Ketika dipinjam, stok buku berkurang 1, dan ada tombol untuk mengembalikan buku!"

1. Database Buat Tabel Peminjaman di phpMyAdmin

CREATE TABLE peminjaman_buku (
    id_pinjam INT(11) AUTO_INCREMENT PRIMARY KEY,
    id_buku INT(11) NOT NULL,
    nama_peminjam VARCHAR(100) NOT NULL,
    tgl_pinjam DATE NOT NULL,
    tgl_kembali DATE NULL,
    status ENUM('Dipinjam', 'Dikembalikan') DEFAULT 'Dipinjam'
);

2. Controller application/controllers/admin/Peminjaman_buku.php

<?php
class Peminjaman_buku extends CI_Controller {

    public function __construct(){
        parent::__construct();
        if($this->session->userdata('hak_akses') != '1'){ redirect('login'); }
    }

    // 1. TAMPIL TRANSAKSI PEMINJAMAN (JOIN DENGAN TABEL BUKU)
    public function index() {
        $data['title'] = "Transaksi Peminjaman Buku";
        $data['peminjaman'] = $this->db->query("SELECT p.*, b.judul_buku, b.kode_buku 
                                                FROM peminjaman_buku p
                                                JOIN inventaris_buku b ON p.id_buku = b.id_buku
                                                ORDER BY p.id_pinjam DESC")->result();

        $this->load->view('template_admin/header', $data);
        $this->load->view('template_admin/sidebar');
        $this->load->view('admin/peminjaman_buku/data_peminjaman', $data);
        $this->load->view('template_admin/footer');
    }

    // 2. FORM PINJAM (AMBIL DATA BUKU YANG STOK > 0 UNTUK DROPDOWN)
    public function tambah_peminjaman() {
        $data['title'] = "Form Peminjaman Buku";
        $data['buku'] = $this->db->query("SELECT * FROM inventaris_buku WHERE stok > 0")->result();

        $this->load->view('template_admin/header', $data);
        $this->load->view('template_admin/sidebar');
        $this->load->view('admin/peminjaman_buku/tambah_peminjaman', $data);
        $this->load->view('template_admin/footer');
    }

    // PROSES PINJAM & KURANGI STOK OTOMATIS
    public function tambah_peminjaman_aksi() {
        $id_buku = $this->input->post('id_buku');
        $data = array(
            'id_buku'       => $id_buku,
            'nama_peminjam' => $this->input->post('nama_peminjam'),
            'tgl_pinjam'    => $this->input->post('tgl_pinjam'),
            'status'        => 'Dipinjam'
        );
        $this->ModelPenggajian->insert_data($data, 'peminjaman_buku');

        // LOGIKA PENGURANGAN STOK BUKU:
        $this->db->query("UPDATE inventaris_buku SET stok = stok - 1 WHERE id_buku = '$id_buku'");

        $this->session->set_flashdata('pesan', '<div class="alert alert-success">Peminjaman berhasil dicatat & stok buku berkurang 1!</div>');
        redirect('admin/peminjaman_buku');
    }

    // 3. LOGIKA PENGEMBALIAN BUKU (UBAH STATUS & TAMBAH KEMBALI STOK)
    public function kembalikan_buku($id_pinjam, $id_buku) {
        $data = array(
            'status'      => 'Dikembalikan',
            'tgl_kembali' => date('Y-m-d')
        );
        $this->db->where('id_pinjam', $id_pinjam);
        $this->db->update('peminjaman_buku', $data);

        // KEMBALIKAN STOK BUKU (+1):
        $this->db->query("UPDATE inventaris_buku SET stok = stok + 1 WHERE id_buku = '$id_buku'");

        $this->session->set_flashdata('pesan', '<div class="alert alert-info">Buku berhasil dikembalikan & stok bertambah!</div>');
        redirect('admin/peminjaman_buku');
    }
}

4. Tanya Jawab Dosen Saat Live Coding (Jawaban Elegan & Percaya Diri)

Pertanyaan Penguji Jawaban Tepat & Berbobot
"Bagaimana alur stok bisa berkurang saat transaksi dibuat?" "Saat form disubmit, Controller mengeksekusi INSERT ke tabel transaksi, kemudian langsung mengeksekusi query UPDATE inventaris_buku SET stok = stok - 1 WHERE id_buku = '$id' sehingga stok di tabel master langsung terpotong secara realtime."
"Mengapa Anda menggunakan JOIN pada query data peminjaman?" "Karena tabel peminjaman hanya menyimpan id_buku sebagai foreign key. Dengan menggunakan JOIN inventaris_buku ON p.id_buku = b.id_buku, kita bisa menampilkan judul buku dan kode buku secara otomatis tanpa duplikasi data (prinsip normalisasi database)."
"Kenapa Anda tidak membuat method baru di ModelPenggajian?" "Karena di CodeIgniter 3 arsitektur sistem saya sudah memiliki Model dengan fungsi generic reusable (insert_data, update_data, delete_data). Ini menerapkan prinsip Clean Code (DRY - Don't Repeat Yourself) sehingga tidak perlu membuat query berulang untuk operasi CRUD dasar."
Cheat-Sheet Adaptasi Cepat ke Tema Lain:
Jika dosen memberi tema lain saat ujian:
  • Rental Mobil: Ganti inventaris_buku jadi data_mobil (nama, plat, harga), dan peminjaman_buku jadi sewa_mobil.
  • Apotek / Klinik Obat: Ganti inventaris_buku jadi data_obat (nama, jenis, stok), dan peminjaman_buku jadi resep_obat.
  • Inventaris Barang Kantor: Ganti inventaris_buku jadi data_barang, dan peminjaman_buku jadi peminjaman_alat.
